# 代码文档

这里记录 WorkAgentHarness 自身代码的结构与行为，供读代码和定位调用链时查阅。它和 `doc/dev/学习手册/` 的区别是：学习手册按功能路线组织；代码文档按真实代码模块和符号组织。

当前 WorkAgentHarness 仍从学习清单逐项实现。开始形成模块代码后，再按实际目录增补文档；不要为了预设章节先造空模块文档。文档中的路径、符号、配置和示例必须能在标注的 WorkAgentHarness commit 中找到。

每篇代码说明建议包括：

- 模块职责、边界，以及它不负责的事；
- 真实入口、注册点、调用者和关键调用链；
- 主要类型、状态/数据归属、读写方和生命周期；
- 配置、依赖、错误处理、权限与并发边界；
- 相关测试及其层级（unit/integration/e2e）；
- 关联功能 ID、源码 commit 和与 EvoFlow 的差异。

功能实现状态统一维护在[功能清单](../dev/学习手册/功能清单.md)，不要在代码说明里复制一份“已完成”状态。
