# 唯一活功能清单

## 记录规则

- 一行对应一个独立行为/生命周期/权限边界，ID 稳定且不因章节调整改变。
- 每个 ID 开始前冻结 EvoFlow、AgentFlow、WorkAgentHarness 三方 commit；记录精确路径、符号、真实入口、配置/外部依赖、测试层级和用户文档。
- 状态只能由证据推进：待盘点 → 已盘点 → 已理解 → 最小闭环 → 功能补齐中 → 边界待验 → 已验收；有依据排除需记录原因和替代。
- “代码存在”“单测通过”“mock 成功”不能替代真实入口验收。权限、失败、并发、取消、重启/恢复中适用项都要核验。
- 验收证据记录操作/命令、依赖是真实还是 fake、预期与实测、日期和 WorkAgentHarness commit。差异/未验证项必须明确。
