# 功能式学习手册

以 EvoFlow 为源码教材，和 AgentFlow 第一遍实现对照，在 WorkAgentHarness 中实验与重做。章节按用户可观察功能组织，允许随着源码发现调整，不用 M0–M8 作为新课程结构。

1. 先看[课程目录](课程目录.md)，了解分篇、章节和功能 ID；再读[总规划](../../系统学习路线-总规划.md)。
2. 在[功能地图](功能地图.md)中选择场景；初学建议从对话运行时开始。
3. 在[功能单元路线](功能单元路线.md)按具体行为学习，从最小闭环逐层补到快照对齐；在[功能清单](功能清单.md)查看每个 ID 的唯一状态和证据。
4. 在功能单元路线中按每个 ID 完成理解、最小实验、功能补齐和边界验收。
5. 更新[学习记录](../学习记录/README.md)，代码结构说明放在[doc/code](../../code/README.md)，工程过程放在[doc/dev](../README.md)，最终使用[最终验收](最终验收.md)。
