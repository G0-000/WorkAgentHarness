# WorkAgentHarness × EvoFlow 学习课程目录

> 阅读路径由“先理解单个请求怎样工作”逐步扩展到“Agent 如何完成复杂任务、连接外部系统并作为完整产品运行”。篇和章是阅读组织方式，不是 M0–M8 式的开发里程碑；每一章都围绕功能行为，按最小闭环→功能补齐→边界验收推进。某项功能可提前学习，但不能因为章节跳转而缩小快照范围。
>
> **章节详解和验收标准唯一来源**：[功能单元路线](功能单元路线.md)。下面每章列出对应功能 ID，状态只在[功能清单](功能清单.md)更新。括号内 ID 可拆分，但不可静默遗漏。

## 文档分区：学习、代码和开发

- **学习路线**：本课程目录、[功能单元路线](功能单元路线.md)、[功能清单](功能清单.md)和学习记录，回答要学哪些行为、每步怎样验收。
- **代码文档**：[doc/code](../../code/README.md) 按 WorkAgentHarness 实际模块记录职责、调用链、数据和边界；等对应代码出现后再补具体模块说明。
- **开发文档**：[doc/dev](../README.md) 记录工程环境、架构决策、开发规范、实现过程和工程验收。

功能实现状态只在功能清单维护；代码文档和开发文档引用功能 ID，不重复维护状态。

## 第一篇：跑通一条可持续对话

先从最短用户旅程理解配置、模型、Agent、会话和恢复；再扩展进程入口与平台适配。

1. **第 1 章｜认识三份代码与源码边界**：EvoFlow / AgentFlow / WorkAgentHarness 的分工、EvoFlow app→core 依赖方向、如何冻结 commit 和追真实 caller。无功能 ID；参考[功能地图](功能地图.md)和[源码分层起点](../学习记录/起点/EvoFlow分层源码阅读.md)。
2. **第 2 章｜配置、模型和凭证**：配置加载、校验、provider 解析、凭证和模型能力。`WAH-RUN-001–002`。详见[运行时单元](功能单元路线.md#对话运行时和持久化)。
3. **第 3 章｜Agent 图、角色与对话轮次**：Agent 如何构建，消息如何进入图，thread 如何续接。`WAH-RUN-003–004`。详见[运行时单元](功能单元路线.md#对话运行时和持久化)。
4. **第 4 章｜消息、Session、Checkpoint 与持久化**：业务历史与运行状态的区别、存储、恢复、迁移和清理。`WAH-RUN-005–006`。详见[运行时单元](功能单元路线.md#对话运行时和持久化)。
5. **第 5 章｜运行生命周期、CLI 与本地服务**：启动、取消、结束、恢复、命令行和 stdio/App Server 协议。`WAH-RUN-007–009`、`WAH-API-009`。详见[运行时与入口单元](功能单元路线.md#对话运行时和持久化)。

## 第二篇：理解 Agent 的核心工作能力

学习 Agent 怎样调用工具、管理有限上下文、持续输出，再扩展到记忆、知识和代码理解。

6. **第 6 章｜工具目录、参数、调用和宿主操作**：tool catalog、schema、结果、内置工具、文件/终端工具和 ZCode 工具桥。`WAH-TOOL-001–004`、`WAH-TOOL-009`。详见[工具单元](功能单元路线.md#工具中间件事件和调度)。
7. **第 7 章｜Middleware、上下文预算与压缩**：调用链、注入信息、token 估算、历史整理和压缩恢复。`WAH-TOOL-005`、`WAH-TOOL-007`、`WAH-MEM-001`、`WAH-MEM-008`。详见[工具单元](功能单元路线.md#工具中间件事件和调度)和[上下文单元](功能单元路线.md#上下文记忆资产和反思)。
8. **第 8 章｜流事件从生产到界面**：token、工具活动、错误和终态如何经由 SSE/客户端被消费；检查断流、取消和恢复。`WAH-TOOL-006`、`WAH-API-002`、`WAH-UI-002`、`WAH-UI-004`。详见[工具单元](功能单元路线.md#工具中间件事件和调度)与[HTTP 入口单元](功能单元路线.md#http-gateway渠道和-app-server)。
9. **第 9 章｜上下文、短期/长期记忆与资产**：记忆存取、召回、巩固、注入预算、资产/产物/item/reflection 生命周期。`WAH-MEM-002–007`。详见[记忆单元](功能单元路线.md#上下文记忆资产和反思)。
10. **第 10 章｜上传、文档知识库与引用**：文件生命周期、解析切块、知识库索引、Embedding/向量检索和引用来源。`WAH-KNOW-001–005`。详见[知识单元](功能单元路线.md#知识上传和代码索引)。
11. **第 11 章｜代码索引与代码上下文**：符号/LSP/tree-sitter 索引、增量更新、检索和 Agent 上下文注入。`WAH-KNOW-006–007`。详见[知识单元](功能单元路线.md#知识上传和代码索引)。

## 第三篇：委派执行与安全边界

从一个受限子任务开始，逐步增加并发、沙箱、审批、权限和取消传播。

12. **第 12 章｜子代理注册、分派与结果汇总**：registry、任务输入输出、并行/后台任务、超时与部分失败。`WAH-EXEC-001–002`、`WAH-PLAN-004`。详见[执行单元](功能单元路线.md#执行子代理权限与隔离)。
13. **第 13 章｜Sandbox 与危险操作审批**：执行 provider、隔离级别、权限 preset、审批状态机和审计。`WAH-EXEC-003–004`、`WAH-GOV-008`。详见[执行单元](功能单元路线.md#执行子代理权限与隔离)和[治理单元](功能单元路线.md#身份授权组织管理安全策略和许可)。
14. **第 14 章｜Session 工具绑定、取消和资源清理**：每个会话可用能力、取消传播、文件/命令边界、断连和 finally 清理。`WAH-EXEC-005–007`、`WAH-RUN-007`。详见[执行单元](功能单元路线.md#执行子代理权限与隔离)。

## 第四篇：计划、协作和长任务

在稳定的对话与执行基础上，让 Agent 拆目标、组织协作、运行工作流并从中断处恢复。

15. **第 15 章｜Plan、目标图与任务拆解**：计划目录与解析、目标拆解、依赖、状态推进和重规划。`WAH-PLAN-001–002`。详见[计划单元](功能单元路线.md#计划协作工作流和探索)。
16. **第 16 章｜协作账本、多 Agent 分工与汇总**：任务分配、授权、结果流、冲突处理和部分失败。`WAH-PLAN-003–004`。详见[计划单元](功能单元路线.md#计划协作工作流和探索)。
17. **第 17 章｜Workflow、Stage 与探索图**：工作流定义/运行、阶段上下文、探索预算、搜索路由、思维图。`WAH-PLAN-005–008`。详见[计划单元](功能单元路线.md#计划协作工作流和探索)。
18. **第 18 章｜暂停、恢复与重复执行安全**：跨 session、workflow、checkpoint 和任务账本梳理恢复语义。`WAH-PLAN-009`、`WAH-RUN-005–007`。详见[计划单元](功能单元路线.md#计划协作工作流和探索)。
19. **第 19 章｜工具调度、定时自动化与主动任务**：局部调度、automation、时区/重启补偿、heartbeat、decision gate 和渠道通知。`WAH-TOOL-008`、`WAH-AUTO-001–006`。详见[调度与自动化单元](功能单元路线.md#自动化调度与主动任务)。

## 第五篇：扩展能力和外部入口

从本地协议和单一入口开始，学习外部工具、插件、Agent 互操作、HTTP/Gateway 和消息渠道。

20. **第 20 章｜MCP 连接与工具/资源生命周期**：server 配置、连接池、OAuth、工具/资源/提示发现和 Agent 注入。`WAH-EXT-001–003`。详见[MCP 单元](功能单元路线.md#mcp插件技能社区和-agent-间互操作)。
21. **第 21 章｜Plugin、Skills、Capability 与社区集成**：安装加载、权限、技能解析/选择、provider 集成和运行桥接。`WAH-EXT-004–008`。详见[扩展单元](功能单元路线.md#mcp插件技能社区和-agent-间互操作)。
22. **第 22 章｜外部 Agent 与 A2A**：adapter、能力发现、Agent Card、meeting、认证和协议错误处理。`WAH-EXT-009–010`。详见[互操作单元](功能单元路线.md#mcp插件技能社区和-agent-间互操作)。
23. **第 23 章｜HTTP API、Gateway 版本与语音**：服务启动、依赖注入、API/SSE、v4、speech、兼容与 Runtime port。`WAH-API-001–004`、`WAH-API-008`。详见[HTTP 入口单元](功能单元路线.md#http-gateway渠道和-app-server)。
24. **第 24 章｜消息渠道、MessageBus 与 ChannelManager**：渠道适配器、事件持久化、入站路由、Agent 执行和出站回复闭环。`WAH-API-005–007`。详见[渠道单元](功能单元路线.md#http-gateway渠道和-app-server)。

## 第六篇：治理、运维和完整产品

把身份权限、观测评估、Web/桌面用户旅程连在一起，最后按端到端场景关闭差异。

25. **第 25 章｜身份、ACL、组织、License 与管理后台**：principal、workspace 可见性、JWT/OIDC 路由矩阵、guardrails、组织分发、许可和审批。`WAH-GOV-001–008`。详见[治理单元](功能单元路线.md#身份授权组织管理安全策略和许可)。
26. **第 26 章｜Trace、诊断、成本指标与 Eval**：跨层关联、活动状态、日志诊断、缓存/成本/延迟指标、质量评测和回归。`WAH-OBS-001–006`。详见[观测评估单元](功能单元路线.md#可观测性调试和评估)。
27. **第 27 章｜Web、桌面、ZCode 与完整用户旅程**：页面/会话/设置、trace 展示、ZCode UI/RPC/provider、Tauri IPC/权限/发布、语音面板。`WAH-UI-001–011`。详见[产品界面单元](功能单元路线.md#web桌面产品和-zcode-子系统)。
28. **第 28 章｜跨域集成、差异关闭与系统验收**：按唯一功能清单统计状态，用真实入口验收对话、工具、安全、恢复、Gateway/渠道和 Web/桌面闭环。无新增功能 ID；按[最终验收](最终验收.md)收口。
