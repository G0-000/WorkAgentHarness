## 第 4 章

**验收对象**：Agent 构建与单轮执行、thread 续跑、持久化计数。

### L1 单轮

```text
cd /Users/main/WorkAgentHarness/backend
uv run --project packages/harness python -m workagentharness.cli.main \
  --config config.yaml --db /tmp/verify-ch3.db --once "你好"
```

实测输出：

```text
thread=ba41e9f49bf14f45bf71a87b6193149c run=114258c7c6174a0da287de58b3ae03bd
助手> 已收到（第 1 轮）：你好
```

### L2 同 thread 续跑

```text
uv run ... --db /tmp/verify-ch3.db --thread ba41e9f49bf14f45bf71a87b6193149c --once "继续"
```

实测输出：

```text
thread=ba41e9f49bf14f45bf71a87b6193149c run=024e5c82ebda4e7b8f14e51fa9075348
助手> 已收到（第 2 轮）：继续
```

**thread id 不变、run id 变化、轮数递增** —— 三项同时成立才算续跑，只看到"有回复"不算。

### L3 库计数（三表）

```text
sessions 1
messages 4
runs 2
```

一轮问答产生 2 条 message（用户 + 助手），两轮共 4 条；两个 run 对应两次执行；session 仍为 1（同 thread 复用）。**三个数要互相解释得通**，不能只报总数。

**第 4 章结论**：已验收（真实本地 SQLite，非 mock）。
