> 没有测试文件的章节，不会因此变成"已通过"；有测试文件的章节，也不等于整章全部完成（未覆盖项见各章验收节）。

## 1. 怎么跑

- 全部：`uv run --project packages/harness python tests/run_chapter_tests.py`（工作目录 `backend/`）
- 单章：`uv run --project packages/harness python tests/run_chapter_tests.py 3`
- 测试框架：标准库 `unittest`（仓库未引入 pytest，避免为测试改依赖）。
- 依赖：全部 `provider: fake`，不联网、不需要 Key；数据库用临时目录，跑完自动删。

## 4. 边界（必须和设备能力对齐）

- **第 2 章**依赖本机 `/Users/main/EvoFlow`；换机器会跳过（skip），跳过不算通过。
- **第 10.2 节**（Browser Bridge / Computer Use）本仓无实现代码，**没有任何测试**；不得因为"第 10 章测试通过"就认为 10.2 完成。
- **终端工具测试**会真的起子进程；不执行破坏性命令，`force:` 只用无害命令验证放行。
- **第 19–60 章**没有任何测试文件；它们是设计篇，禁止出现"测试通过"的字样。第 1–18 章已有 17 个测试文件、138 例，属运行验收（第 1 章为理解验收）。
