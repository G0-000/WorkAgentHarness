## 串联路径（实际接线）

```text
用户输入
  ▼
MemoryRuntimeMiddleware.before_model
  · 读长期（agent_memory，按实体）
  · 拼记忆块 → pinned 的 memory_injection 消息
  ▼
模型回答（fake：回显 / 工具 / 回述）
  ▼
MemoryRuntimeMiddleware.after_model
  · 规则抽取 → preference/behavior 进长期，context 只进短期
  ▼
Run 结束（RunService）
  ▼
收尾（调用方显式触发）
  · AssetStore.write → 文件落盘 + artifacts 登记
  · record_wrapup → run_wrapups 写 outcome/reflection/initiatives
  · clear_thread → 清 task_memory
```

## 失败路径（真实用例，不是文字承诺）

- 空内容 / 未知分类 / confidence 越界 → `ValueError`（第 15 章 `test_invalid_inputs_raise`）。
- 非法实体类型或 id → 构造即 `ValueError`（第 15 章 `test_invalid_entity_rejected`）。
- 注入层拿到空记忆 → 不插消息（第 16 章 `test_no_memory_no_injection`）。
- 知识类请求 → 不产记忆（第 16 章 `test_knowledge_question_is_not_memory`）。
- 读不存在的资产 → `FileNotFoundError`（第 17 章 `test_read_missing_raises`）。
- 交班不写 outcome → 拒绝落库（第 17 章 `test_empty_outcome_rejected`）。
