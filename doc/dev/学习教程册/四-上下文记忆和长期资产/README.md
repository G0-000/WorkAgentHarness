## 本篇三条澄清（读之前先看，避免按名字查错）

1. **"知识图谱"在知识库侧，不在记忆侧**。`knowledge/owned/kg.py`（379 行，`upsert_node`/`upsert_edge`/`add_triples`，`kg_*` 表，SQLite 无 Neo4j）是真实实现；记忆侧实体图已退役（`knowledge/owned/worker.py:95` 注释）。旧文档把"记忆巩固"与"知识图谱"并列在一章是错位，图谱归第 21 章。
2. **"提示注入"是注入过滤**，不是防恶意 prompt injection。原版对应 `_standing_fact_allowed(fact, *, chat_compact)`：决定哪条记忆能进提示词。
3. **两个 `reflection` 同名不同义**：`evoflow.reflection`（`resolve_class`/`resolve_variable`）是 Python 反射工具；业务"反思"是 `proactive_submit_work` 的 `reflection` 参数。
