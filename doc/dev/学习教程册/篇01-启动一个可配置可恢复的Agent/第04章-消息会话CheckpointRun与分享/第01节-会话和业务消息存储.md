# 第 4 章 · 第 1 节｜会话和业务消息存储

## 本节业务问题

UI 要展示会话列表和消息历史，必须有可查询的业务数据；Agent 内部状态由 checkpointer 管理，是另一种用途。两种存储不能混为一个“聊天记录”。

## 调用流程

```text
create(session_id, owner_id)
  → RunService 接收文本
  → 写 user message
  → Agent 调用
  → 写 assistant message
  → list_messages(session_id, owner_id)
```

## 代码解释

- [schema.py](../../../../../backend/packages/harness/workagentharness/persistence/schema.py)：定义 sessions、messages、runs 三张业务表和外键/状态约束。
- [db.py](../../../../../backend/packages/harness/workagentharness/persistence/db.py)：创建目录、启用外键和 WAL、初始化 schema。
- [session_repository.py](../../../../../backend/packages/harness/workagentharness/persistence/session_repository.py)：参数化 SQL；消息读取通过 owner 条件过滤。
- 当前方法逐条提交，没有分页、迁移框架和整轮事务；章节正文要求在完整对齐前补齐适用的行为。
