## 场景

Agent 的能力不该只来自自己写死的工具。它要能接外部 MCP 服务、加载插件壳、用别人做好的技能包、甚至和别的 Agent 互操作。本篇处理"能力从外面来"这条路。

本章是全篇出口，目前只有设计。
