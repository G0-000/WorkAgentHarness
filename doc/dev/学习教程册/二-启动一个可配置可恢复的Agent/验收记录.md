## 环境与运行验证

依赖已通过 `uv sync` 安装完毕，CLI / thread 恢复 / stdio App Server 均已实测通过（2026-10-22）：

| 检查项 | 命令 | 实测结果 |
|---|---|---|
| 单轮 CLI | `uv run --project packages/harness workagentharness --once "你好"` | 返回「已收到（第 1 轮）：你好」，run 状态 completed |
| 同 thread 恢复 | `--thread <id> --once "再发一条"` | 返回「第 2 轮」，checkpoint 连续计数正常 |
| stdio RPC | `--mode app-server` + 三条 JSON-RPC | initialize / ping / turn/start 均正确返回 |

依赖备注：`langgraph-prebuilt` 需严格锁 `==1.0.8`，1.0.9+ 会因 `ExecutionInfo` 导入失败与 `langgraph<1.0.10` 不兼容。

剩余未验证项见上表「未通过项」，尤其是真实模型调用、取消传播、并发、重启恢复和 EvoFlow 源码对照。
