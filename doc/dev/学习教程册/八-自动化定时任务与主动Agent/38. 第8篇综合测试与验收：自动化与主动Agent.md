## 场景

前七篇的 Agent 都是"你问它才动"。真实办公助理要能在没人说话时自己动：到点跑报表、每天巡检、发现异常主动汇报。本篇处理"计划任务 + 主动触发 + 通知投递"。

## 串联路径（设计）

定义自动化（规则 + 负载）→ 调度器到点触发 → 执行并写运行历史 → 心跳巡检产生主动任务 → 结果通过渠道投递 → 管理界面可查、可停、可改。

### 适用失败路径（设计，未执行）

- 规则非法（cron 解析失败）→ 保存时报错，不进入调度。
- 投递失败 → 记录失败并重试，不静默丢弃。
- 重启补跑 → 已成功的运行不重复执行（幂等）。
