## 场景

用户丢进来一个 PDF、一份会议记录、一个代码仓库，希望 Agent 能"读过再回答"，并且回答能指到具体段落或文件行。本篇解决从原始文件到可检索片段、再到可引用答案的整条链。

本章是全篇出口，目前只有设计。

## 串联路径（设计）

上传文件 → 解析（文本/版面/代码）→ 切块 → 入库 → 建索引 → 检索 → 拼装引用 → 回答里带出处 → 代码场景下按符号定位到文件与行。
