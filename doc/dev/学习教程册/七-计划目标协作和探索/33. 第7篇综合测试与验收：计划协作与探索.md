## 场景

一个复杂任务不能一句话干完：要拆计划、分工、追踪每个人在做什么、探索多条路径、中途暂停再恢复，还要保证重复执行不产生重复副作用。本篇处理"长任务怎么组织"。

本章是全篇出口，目前只有设计。

## 串联路径（设计）

接收复杂目标 → 生成 Plan → 展开 Goal 图 → 分配任务到协作账本 → 执行并记录状态 → 探索分支按预算裁剪 → 中断后按记录恢复 → 重复触发时幂等跳过。

### 适用失败路径（设计，未执行）

- 计划文本无法解析 → 报错并保留原文，不生成空计划。
- 恢复时状态文件损坏 → 拒绝恢复，提示人工确认，不猜断点。
- 重复触发 → 幂等键命中，直接返回既有结果。
