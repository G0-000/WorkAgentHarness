## 场景

前九篇的 Agent 只在本地终端里活着。真实产品要能被网页、被 IM、被别的系统调用：HTTP 起服务、兼容既有协议、把消息投递到不同渠道、反过来接收渠道事件。

本章是全篇出口，目前只有设计。注意区分：第 3 篇只验了"SSE 帧能编码"，本篇要验"服务真起来、外部真能连"。

## 串联路径（设计）

起 Gateway（lifespan 装配依赖）→ 暴露聊天端点 → 客户端发消息 → 走 RunService → 流式返回 → 渠道适配器把消息投递到 IM → 回执落回渠道状态 → 兼容协议路径做代理转换。
