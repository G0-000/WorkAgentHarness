## 场景

一个 Agent 能干活之后，问题变成"谁能让它干、它能碰什么、出事怎么查"。本篇覆盖身份入口、权限守卫、组织分发与 License 审批、日志与成本、评估回归，以及让 Agent 长期像一个"人"的人格内核。

本章是全篇出口，目前只有设计。

## 串联路径（设计）

请求带凭据 → 身份解析（Principal）→ ACL 判定 → 入口守卫 → 进入业务 → 组织/租户隔离 → 运行写 trace 与用量 → 评估样本回放 → 结论回填 → 人格内核按轮次写 SOUL、记忆与承诺。

### 适用失败路径（设计，未执行）

- token 过期 → 拒绝并返回明确状态码。
- 越权 → 拒绝且记录审计，不是"静默放行"。
- 人格记忆写入重复 → 幂等跳过，不重复追加。
