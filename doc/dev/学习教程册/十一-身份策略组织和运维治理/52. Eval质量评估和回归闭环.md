## 场景

你改了提示词，觉得"应该更好了"。但怎么证明？

AI 应用最难的地方：**没有单测**。传统代码改一行跑测试就知道，提示词改一行，没人知道是变好还是变差。

Eval 就是把这件事变成可测的：

1. 准备一批**用例**（输入 + 期望）
2. 跑一遍，拿结果
3. **打分**（不是"对不对"，而是"多对"）
4. 出报表
5. 固定成**回归**：每次改都跑，退步就拦

第 3 点最容易做错：用"完全匹配"打分，结果 100% 失败——因为模型换个说法意思一样。所以要有**语义/业务质量打分**。

## 本节业务问题

| 问题 | 后果 |
|---|---|
| 用例不落文件 | 每次手写，无法回归 |
| 只做完全匹配 | 语义相同也被判错 |
| 只测准确率不测性能 | 变准了但慢了 3 倍 |
| 无基线 | 不知道"这次算好还是差" |
| 无报表 | 数据散落，没法比较 |
| 无安全用例 | 提示词注入没测 |

## EvoFlow 源码阅读路径

| 层 | 文件与真实符号 | 作用 |
|---|---|---|
| ① 用例规格 | `eval/case_spec.py` | **用例的结构定义** |
| ② 引擎 | `eval/eval_engine.py:36` `_now_ms()`；`:40` `_new_run_id()`；`:44` `_new_alert_id()`；`:48` `_table_exists(db, name)` | 跑批 + 落库 + 告警 |
| ③ 业务质量 | `eval/business_quality.py` | **业务口径打分**（不是字符串匹配） |
| ④ 性能 | `eval/performance.py` | 延迟/吞吐 |
| ⑤ 安全 | `eval/security.py` | 安全用例 |
| ⑥ 场景 | `eval/scenarios`（目录） | 分组用例 |
| ⑦ 数据源 | `eval/data_sources.py` | 用例从哪来 |
| ⑧ 适配 | `eval/response_adapters.py` | 不同输出格式归一 |
| ⑨ 报表 | `eval/dashboard.py`、`modules.py`、`pack_architecture.py` | 展示 |

**`_new_alert_id()` 的存在说明 Eval 不只是报表**：它会**产生告警**——分数跌破阈值时主动报。

逐层追读要点：`case_spec` 先看（决定"一个用例长什么样"）；再看 `business_quality` 怎么打分（不是字符串比较）。

## 调用流程

```text
① 定用例    case_spec → 用例文件（输入 + 期望 + 分组）
  ▼
② 跑批      eval_engine → 逐条执行 → _new_run_id
  ▼
③ 归一      response_adapters → 统一输出格式
  ▼
④ 打分      business_quality（业务分）+ performance（性能分）+ security
  ▼
⑤ 落库      _table_exists 检查 → 写结果表
  ▼
⑥ 比对基线  与上次 run 比 → 退步则 _new_alert_id
  ▼
⑦ 报表      dashboard
```

## WorkAgentHarness 现状与设计

**现状**：无 Eval。改了提示词只能靠肉眼看输出。

| 缺口 | 设计方案 | 边界 |
|---|---|---|
| 用例 | `evals/*.jsonl`：`{id, input, expect_contains[], tags[]}` | 单文件 |
| 跑批 | `python -m wah.eval run evals/x.jsonl` | CLI 子命令 |
| 打分 | **关键词命中率**（`expect_contains` 命中数 / 总数） | 不做语义打分 |
| 性能 | 记总耗时，不做基线比较 | — |
| 安全 | 一组固定用例（提示词注入） | 5 条 |
| 报表 | 终端表格输出 | 无 dashboard |
| 告警 | 不做 | — |

**必须写清**：本项目用**关键词命中**打分，这是最粗糙的方式。原版有 `business_quality` 做业务口径打分。**不要把这写成"已对齐"**。

## 与 EvoFlow 的差异

| 项 | EvoFlow | 本项目 |
|---|---|---|
| 用例规格 | `case_spec` | 简化 JSONL |
| 打分 | `business_quality` + `performance` + `security` | 关键词命中率 |
| 基线比对 | 有 | 不做 |
| 告警 | `_new_alert_id` | 不做 |
| 报表 | `dashboard` | 终端表格 |
| 场景分组 | `scenarios` 目录 | `tags` 字段 |
