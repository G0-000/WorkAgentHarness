## 场景

两个人在同一个部署里用 Agent：

- 张三的会话，李四不能看到；
- 但公司公告是所有人可见；
- 某个项目空间，只有项目成员能进。

要回答"能不能看"，需要三个东西：

1. **你是谁**（Principal）
2. **这条资源属于哪个作用域**（Scope：个人 / 组 / 组织）
3. **你对这个作用域有没有授权**（Grant / ACL）

少任何一个，判断都会错。最常见错法：只判断"有登录"，不看"这条资源属于谁"——结果 A 能看到 B 的会话。

## 本节业务问题

| 问题 | 后果 |
|---|---|
| 无主体概念 | 所有请求"匿名"，无法区分 |
| 作用域不分层 | 个人资源与组织资源混在一起 |
| 授权只查"是否登录" | A 能看到 B 的数据 |
| 会话不盖归属戳 | 列表接口按全表返回 |
| 资源引用不编码 | `kind` + `id` 拼一起，解析时分不清 |
| 无组织管理员概念 | 谁都能改组织级配置 |

**`session_ownership.py` 的两个方法是配对设计**：`stamp_session_ownership` 写入时打归属，`session_visible_to_principal` 读取时判可见。**缺一个就漏**——只做读取判断，历史数据没有归属戳就判不了；只做写入盖章，列表接口还是全表返回（`acl_session_list_filter_sql` 就是给列表加 SQL 过滤）。

逐层追读要点：`scope_id(kind, ref)` 是所有作用域的生成函数，先看它怎么拼、再看三种 `*_scope` 怎么调它。

## 调用流程

```text
HTTP 请求进来
  ▼
① 取身份     resolve_authz_from_request(request)
  │              └ 无信号（_has_auth_signals 为假）→ 匿名/拒绝
  ▼
② 解析主体    principal_from_row → Principal
  ▼
③ 算作用域    scope_id(kind, ref) → personal / group / org
  ▼
④ 判授权      principal_entitled_to_scope(scope, grants) → 403 或放行
  ▼
⑤ 判资源      require_thread_visible(request, thread_id)
  ▼
⑥ 列表过滤    acl_session_list_filter_sql → 只返回可见的
```

## WorkAgentHarness 现状与设计

**现状**：**完全没有身份体系**。CLI 单用户，`sessions` 表只有一个隐式用户。

| 缺口 | 设计方案 | 边界 |
|---|---|---|
| 主体 | `Principal(id, kind, org_id)`，kind 只有 `local` | 不做用户体系 |
| 作用域 | 只做两层：`personal:<id>` / `org:<id>` | 不做 group |
| 会话归属 | `sessions.owner_principal` 列，创建时写入 | 对齐 `stamp_session_ownership` |
| 读取过滤 | `list_sessions(principal)` 带 `WHERE owner_principal=?` | 对齐 `acl_session_list_filter_sql` |
| 授权 | `grants(principal_id, scope_id)` 单表 + 精确匹配 | 不做继承 |
| 入口守卫 | **不做 HTTP 就无入口守卫** | 第 44 章若起服务才需要 |
| 组织管理员 | 不做 | — |

**要写清的一条**：本项目是单用户 CLI，全套 ACL 现在**没有使用场景**。这一章的价值是"理解结构"，不是"现在就上"。

## 与 EvoFlow 的差异

| 项 | EvoFlow | 本项目 |
|---|---|---|
| 主体类型 | `Principal` TypedDict | 同（简化字段） |
| 作用域层数 | 个人 + 组 + 组织 | 个人 + 组织 |
| 授权模型 | Grant + scope 判定 | 精确匹配 |
| 会话归属 | 盖章 + 可见性 + SQL 过滤三件套 | 列 + WHERE |
| 入口守卫 | `http_guard` 三个函数 | 无（无 HTTP） |
| 组织管理员 | `require_org_admin` | 不做 |
| 参与者 | `add_session_participant` | 不做 |
