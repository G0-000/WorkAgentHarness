## 场景

用户在浏览器里打开页面：

1. 左边一列会话（"昨天那个财报分析在哪"）
2. 点进去看历史消息（**要能搜**）
3. 输入框发消息 → 流式返回
4. 想看"上周问过什么" → 搜索

这四件事在服务端要各有对应：静态资源、会话列表、消息搜索、流式聊天。

## 本节业务问题

| 问题 | 后果 |
|---|---|
| 静态资源路径写死 | 打包后 404 |
| 公开路径不区分 | 登录页也被拦，或私有接口被放行 |
| 会话列表无时间过滤 | 返回几千条，页面卡死 |
| 搜索只搜标题 | 找不到"那句话在哪个会话" |
| token 提取不统一 | 一个接口从 header 取、一个从 query 取 |

## EvoFlow 源码阅读路径

| 层 | 文件与真实符号 | 作用 |
|---|---|---|
| ① 静态目录 | `webui/static.py:21` `_frozen_base_dir()`；`:28` `resolve_evopanel_dist_dir()` | 打包 vs 开发两种路径 |
| ② 挂载 | `:71` `mount_evopanel_static(app: FastAPI)` | 挂到 FastAPI |
| ③ 公开路径 | `webui/middleware.py:76` `_is_public_path(path, method="GET")`；`:61` `_is_public_share_get(path, method)` | **哪些不需要登录** |
| ④ token 提取 | `:101` `_extract_token(request)`；`:124` `_is_api_request(path)` | 统一取 token |
| ⑤ 会话搜索 | `admin/sessions.py:94` `_search_sessions(...)`；`:29` `_search_messages(...)`；`:15` `_cutoff_iso(max_age_days)` | **会话级 + 消息级两种搜索** |

**`_is_public_share_get` 单独存在**说明"分享链接"是另一种公开语义（只读、GET、带 share token），不能和"登录放行"混同。

逐层追读要点：`_frozen_base_dir` 与 `resolve_evopanel_dist_dir` 的差异（打包态 vs 开发态）。

## 调用流程

```text
浏览器 GET /
  ▼
① 判公开    _is_public_path(path, method) → 无需登录
  ▼
② 取 token   _extract_token(request) → 校验
  ▼
③ 静态       mount_evopanel_static → 返回 dist/index.html
  ▼
④ 会话列表   带 max_age_days 过滤 → 只返回近 N 天
  ▼
⑤ 搜索      _search_sessions / _search_messages
  ▼
⑥ 聊天 POST → 流式 SSE
```

## WorkAgentHarness 现状与设计

**现状**：
- `app_server/sse.py` 有 `build_sse_response` / `create_sse_app`（starlette），**无 fastapi、无 uvicorn、无前端产物、无独立服务**。
- 会话与消息在 `persistence/` 三表里，但没有"列表 API"和"搜索"。

| 缺口 | 设计方案 | 边界 |
|---|---|---|
| 静态资源 | **不做**（无前端） | — |
| 会话列表 | 函数 `list_sessions(limit, since)` | 无 HTTP 包装 |
| 消息搜索 | SQL `LIKE` 扫 `messages.content` | 不做全文索引 |
| 公开路径 | 不做（无中间件） | — |
| 流式 | 已有 `encode_sse_event`，但只在 CLI 打印 | 无浏览器端 |
| 服务 | **不启动** | 无 uvicorn |

**必须写清**：本章整章在本项目**只有"数据层能力"（列表/搜索），没有产品层**。写它是为了让读者知道 Web 那一层需要什么，不是"我们做了"。

## 与 EvoFlow 的差异

| 项 | EvoFlow | 本项目 |
|---|---|---|
| 框架 | FastAPI | starlette（无服务） |
| 前端 | `evopanel dist` 独立产物 | 无 |
| 静态挂载 | `mount_evopanel_static` | 不做 |
| 公开路径 | `_is_public_path` + 分享语义 | 不做 |
| 会话列表 | 有 API | 仅函数 |
| 搜索 | 会话级 + 消息级 | 仅消息级 LIKE |
| 流式 | 浏览器 SSE | CLI 打印 |
