## 场景

用户说了一句话：

> "把 `/tmp/反馈.csv` 里的差评挑出来，整理成报告，发到我的飞书。"

这一句话要经过系统的多少层：

| 步 | 用户看到 | 系统里发生什么 |
|---|---|---|
| 1 | 输入框出现文字 | 消息入库（`messages`） |
| 2 | "正在思考…" | Agent 构造 + 上下文装配 |
| 3 | 工具调用卡片 | 工具目录解析 + 参数校验 |
| 4 | "读取文件…" | 文件工具（只读边界） |
| 5 | 结果返回 | 工具结果截断 + 回灌 |
| 6 | 多轮继续 | 上下文预算 + 压缩 |
| 7 | "生成报告中…" | 二次模型调用 |
| 8 | 报告完成 | 产物落盘 + 事件推送 |
| 9 | 飞书收到 | 渠道投递（含退订判断） |
| 10 | 会话可回看 | checkpoint 恢复 |

**9 步里任何一步没接上，用户看到的就是"卡住"或"没反应"**。而"哪一步断了"，只有把链路画全才看得出来。
