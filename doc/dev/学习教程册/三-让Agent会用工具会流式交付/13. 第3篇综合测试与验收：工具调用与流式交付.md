## 场景

Agent 会说话了还不够：用户要它算个数、读个文件、跑条命令，并且希望字是一个一个蹦出来的，不是等十秒才吐一整段。本篇五章分别做工具目录、内置工具、宿主边界、上下文中间件、流式事件，本章把它们串成一条可观察的链路。

## 串联路径

`ToolCatalog`（4 个工具 / 3 个档位）→ 工具解析与别名 → 内置计算/文件工具 → 宿主终端工具的危险命令闸门 → 结果截断协议 → 中间件预算与工具审计 → `--stream` 文本增量 / `--sse` 事件帧 → `EventBuffer` 断线补发。

### 三条拒绝路径的共性

第 4、5、6 条是同一类设计：**默认拒绝，显式放开**。表达式走 AST 白名单、文件走工作区解析、命令走危险模式表，三者都不依赖调用者自律。这类边界只有"拒绝了"才算验过，"应该会拒绝"不算。

### 本章不能误报为通过

- **模型自动调用工具**：fake 模型不触发工具，本章验的是"工具能被调用且边界生效"，不是"模型会自己选工具"。
- **独立 HTTP 服务进程**：没有 uvicorn/fastapi，`build_sse_response` 只构造响应对象。
- **真实客户端连端点**：不成立。
- **持久化补发**：`EventBuffer` 是内存，重启即丢。
- **`step` / `usage` / `interrupt` 事件**：未实现。
- **BrowserBridge / ComputerUse**：未实现，仅登记。
