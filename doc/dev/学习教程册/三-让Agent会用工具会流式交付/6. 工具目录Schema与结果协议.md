## 本章要做出的东西

把"模型能调用什么工具"从散落的代码变成一份**可查询的目录**，并给所有工具的返回值定一种**统一协议**。做完这两件事，Agent 才能从"只会聊天"变成"会干活"，而且干活的每一步都可审计。

具体交付：
1. `ToolCatalog`：注册、别名、按名解析、导出 schema、导出元数据。
2. `ToolResult` + `shape_result`：成功/失败/截断/错误类别统一收敛。
3. Agent 侧接线：`create_agent(tools=[...])` 真正拿到工具，而不是 `tools=[]`。

## 跟着写代码：目录 + 协议

### 1. 工具结果协议

```python
MAX_RESULT_CHARS = 8000

@dataclass(frozen=True)
class ToolResult:
    ok: bool
    content: str
    error_code: str = ""
    truncated: bool = False
    metadata: dict[str, Any] = field(default_factory=dict)

def truncate_text(text: str, limit: int = MAX_RESULT_CHARS) -> tuple[str, bool]:
    if len(text) <= limit:
        return text, False
    return f"{text[:limit]}\n…（已截断，原文共 {len(text)} 字符）", True
```

### 2. 工具目录

```python
class ToolCatalog:
    def register(self, tool, *, tier="core", aliases=(), source="builtin"):
        name = tool.name
        if name in self._entries:
            raise ValueError(f"工具已存在，拒绝重复注册: {name}")
        self._entries[name] = ToolEntry(tool=tool, tier=tier, aliases=aliases, source=source)
        for alias in aliases:
            self._alias_index[alias] = name

    def langchain_tools(self):
        return [entry.tool for entry in self._entries.values()]
```

## 分层练习与出口

- **L1（已完成）**：注册一个纯函数工具并调用。验收：`--once "计算 (3+4)*2"` 返回 `14`。
- **L2**：参数 schema 与标准结果。验收：打印 `schemas()`，模型能看到 `expression` 参数；工具失败返回 `[ErrorCode]` 而不是抛异常。
- **L3**：别名、来源、按 Agent 过滤、大结果引用。验收：`resolve("calc")` 命中；不同 Agent 拿到不同工具集；读 20 万字符文件不超上下文。
- **L4**：参数错误、重复注册、审计。验收：重名注册抛错；非法表达式返回类别而非崩溃；每次调用有 `tool.start/tool.end` 日志。

**本章出口**：从"模型能看见的工具 schema"追到"实际执行和结果回传"，两步都有代码和验收记录。
