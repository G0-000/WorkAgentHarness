## 本章要做出的东西

给模型装上"手"：一个能算数的计算工具，一个能读文件的文件工具。重点不是"能调用"，而是**每个工具都带边界**：

- 计算工具：只能算数，不能执行任意代码。
- 文件工具：只能读工作区内的文件，不能读 `/etc/passwd`。

## 跟着写代码：安全求值与路径边界

### 1. AST 白名单而不是 eval

```python
_BIN_OPS = {ast.Add: operator.add, ast.Sub: operator.sub, ast.Mult: operator.mul,
            ast.Div: operator.truediv, ast.Pow: operator.pow, ast.Mod: operator.mod}

def _eval_node(node):
    if isinstance(node, ast.Constant):
        if isinstance(node.value, bool) or not isinstance(node.value, (int, float)):
            raise ValueError("只支持数字")
        return node.value
    if isinstance(node, ast.BinOp) and type(node.op) in _BIN_OPS:
        left, right = _eval_node(node.left), _eval_node(node.right)
        if isinstance(node.op, ast.Pow) and abs(right) > 1000:
            raise ValueError("指数过大")
        if isinstance(node.op, (ast.Div, ast.Mod)) and right == 0:
            raise ValueError("除数不能为 0")
        return _BIN_OPS[type(node.op)](left, right)
    raise ValueError(f"不支持的表达式成分: {type(node).__name__}")
```

### 2. 路径归一化三道关

```python
def resolve_in_workspace(path: str) -> Path:
    candidate = Path(path.strip())
    if candidate.is_absolute():
        raise ValueError("不允许绝对路径，请使用工作区内的相对路径")
    root = workspace_root()
    target = (root / candidate).resolve()      # 先归一化，再判断
    if root not in target.parents and target != root:
        raise ValueError("路径越出工作区范围")
    return target
```

**顺序不能反**：先判断字符串前缀再 `resolve`，`foo/../../etc/passwd` 能骗过检查。

### 3. 宿主边界不是提示词

```python
# 错误做法
system_prompt = "只允许读取工作区内的文件，不要读其他路径"

# 正确做法
target = (root / candidate).resolve()
if root not in target.parents:
    raise ValueError("路径越出工作区范围")
```

提示词只是"建议"，代码才是"边界"。模型可以无视提示，但不能无视 `raise`。

## 分层练习与出口

- **L1（已完成）**：临时 workspace 读取文件。验收：`read_text_file("backend/config.yaml")` 返回内容。
- **L2**：接真实入口。验收：Agent 通过 CLI 调用计算工具和文件工具，结果进入 messages 表。

- **L4**：路径逃逸、命令策略、输出上限、危险操作授权。验收：绝对路径被拒、`../` 被拒、软链接逃逸被拒、二进制文件返回 `[NotText]`。

**本章出口**：每种实际开放的工具都有"实现 / 排除"和权限证据。
