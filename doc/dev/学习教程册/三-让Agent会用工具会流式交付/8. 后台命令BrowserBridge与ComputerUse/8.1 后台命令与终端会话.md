# 第 8 章 · 第 1 节｜后台命令与终端会话

## 场景

你让助理去楼下便利店买东西。你会说"买瓶牛奶"，不会让他自己拿你的银行卡、自己决定去哪家店、自己刷多少额度。你会给他：买什么、预算多少、几点回来。

这一节讨论的是"让 Agent 跑命令"：比"读文件"危险一个量级。命令可能删东西、装东西、改系统状态、跑很久不回来。所以本篇**只讲边界与目标，不写实现**。

## 这一节要实现什么功能（目标，当前未实现）

让 Agent 能在受控前提下执行命令：命令策略先判危险等级，破坏性命令要审批，后台任务有会话 ID 可轮询、可停止，输出有上限。

**可验收的行为（目标）**：`ls` 直接执行并返回输出；`rm -rf` 触发审批 interrupt；超时命令被杀掉并返回超时错误码；`session.read` 能拿到增量输出。

**当前状态**：无执行器、无审批中间件、无会话管理，本节只定义风险清单与验收标准。

## 本节业务问题

后台命令工具要回答一串问题，任何一个没答好都不能上线：

| 问题 | 没答好的后果 |
|---|---|
| 允许跑哪些命令 | 模型生成 `rm -rf /` 直接执行 |
| 超时怎么办 | 命令挂住，整个 run 卡死 |
| 输出多大 | 一个 `cat` 大文件把上下文打爆 |
| 谁批准 | 破坏性命令未经用户确认就执行 |
| 进程怎么回收 | 子进程变成孤儿，机器越跑越卡 |
| 环境变量/密钥 | 命令继承宿主环境，把 API Key 打进日志 |

本篇的实现是"最小闭环"：只有计算和只读文件。命令执行留到本篇之后单独做，因为它需要的是**完整治理**，不是一个工具函数。

## 目标调用流程（未实现）

```text
模型 tool_call: run_command(cmd="pytest -q", timeout_s=60)
  ▼
① 命令策略检查
  ├─ 白名单命中？（pytest / ls / cat / git status …）
  └─ 未命中 → [CommandNotAllowed]，交人工审批
  ▼
② 审批（破坏性操作）
  ├─ 需要用户确认 → 事件 interrupt，等待前端批准
  └─ 拒绝 → [ApprovalDenied]
  ▼
③ 沙箱执行
  ├─ 独立进程组（便于整组 kill）
  ├─ 超时到点 → SIGTERM → SIGKILL
  ├─ 输出上限（如 100KB）→ 截断 + 标记
  └─ 环境变量白名单（不继承全部宿主环境）
  ▼
④ 结果整形
  ├─ exit_code / stdout（截断）/ stderr（截断）
  └─ 后台任务 → 返回 task_id，后续用 task_output 轮询
```

## 关键知识点

### 前台命令 vs 后台会话

| | 前台命令 | 后台会话 |
|---|---|---|
| 生命周期 | 一次调用内结束 | 跨多次调用存活（如进入 REPL、跑 server） |
| 状态 | 无需存储 | 需要进程表：task_id → 进程句柄、输出缓冲、状态 |
| 风险 | 超时、输出爆炸 | 进程泄漏、会话被复用做别的事、终端状态污染 |

### 为什么"超时 + kill 进程组"是硬要求

只 `kill(pid)` 不够：shell 会 fork 子进程，父进程死了子进程继续跑。必须 `start_new_session=True` 建独立进程组，超时时 `os.killpg`。

### 输出截断要分 stderr/stdout

命令失败时 stderr 才是关键信息。如果只截断合并输出，可能把错误行截掉、留下无用的进度输出。

### 审批不是"弹个框"，是状态机

```text
pending → approved → running → completed
        ↘ denied
        ↘ timeout（审批超时 = 拒绝，不是放行）
```

审批超时绝不能默认通过——那是安全漏洞。

## 跟着做与验收（本篇为待实现项）

本节不写代码，只给出验收标准；实现放在后续篇（WAH-TOOL-010 状态更新为"待实现"时再动）：

1. 命令白名单：`rm -rf /` 返回 `[CommandNotAllowed]`，不执行。
2. 超时：`sleep 120` 在 5s 内被终止，run 返回 `[Timeout]`，进程组无残留（`ps` 验证）。
3. 输出上限：`cat` 一个 5MB 文件，返回截断内容 + 总大小标注。
4. 审批：破坏性命令产生 `interrupt` 事件；审批超时按拒绝处理。
5. 环境隔离：命令里 `echo $WORKAGENT_MODEL_API_KEY` 输出空（环境变量白名单不包含密钥）。
6. 后台会话：起一个长任务拿到 `task_id`，两次 `task_output` 能取到增量输出，最后 `task_stop` 能真正终止。
