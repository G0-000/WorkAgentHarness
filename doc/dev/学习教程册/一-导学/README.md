# 第 1 篇｜导学：开始之前

这是教程册的导学篇，**两章（第 1 章导学 + 第 2 章篇级验收）、不写业务代码**。它的作用是把三份仓库摆正、把许可证确认清楚、把"从入口追一条消息"这件事练一遍，作为后面所有章节的对照起点。

从第 2 篇起，每章都要求：先读 EvoFlow 真实调用链，再在 WorkAgentHarness 做最小闭环，最后补入口、状态与边界。本导学篇是唯一例外——只读、只记录。

## 开始条件

1. 三份仓库在本地可读、可 `git rev-parse HEAD`。
2. 接受"许可证检查是准备动作，不是知识点考核"，半小时内结束。
3. 准备一个能放图的地方（Markdown、白板、纸都行）。

## 本篇综合练习

只练一件事：**追一条消息**。

1. 从 EvoFlow 的真实 HTTP 入口出发，追到响应返回，画出 6 跳；
2. 人为制造一个失败（例如把模型配置改坏、或让 checkpointer 路径不可写），观察错误在哪一层暴露、业务表有没有留下半条记录；
3. 在 AgentFlow 里对这几跳做一次"有调用者 / 只有代码"的判断。

手工调用内部函数不算完成——必须从入口走。

## 本篇完成标准

- 能不看笔记复述这条消息的 6 跳，每跳报出 `文件::符号`。
- 能说清三仓库角色与 EvoFlow 许可边界（各一句话）。
- 不要求：记住 LICENSE 条款原文、枚举第三方依赖树、审计 AgentFlow 全项目死代码。

状态与功能 ID 只在[唯一状态清单](../../学习手册/功能清单.md)里维护，本篇不重复罗列。
