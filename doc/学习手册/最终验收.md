# 全项目验收与学习收口

收口只引用[功能清单](功能清单.md)的稳定 ID，不复制功能描述。

每项关闭前确认：有 EvoFlow 源码证据且能从真实入口追到状态和结果；能解释关键设计并对比 AgentFlow 第一遍；WorkAgentHarness 有实现和入口，或有充分证据的排除及兼容替代；风险相符的主路径、错误、权限、恢复和集成验收通过；图文实现对应同一源码快照。

验收时按功能清单中的全部 ID 汇总，不在本文件复制或另造功能行。逐项结论写回唯一活功能清单；本文件只记录跨域端到端场景和收口摘要。

系统级场景按盘点结果选择：模型配置和多轮恢复；工具执行、流式事件、权限拒绝、失败和取消；基于文档/代码的复杂任务保存恢复；真实 Gateway/渠道/UI 用户旅程；运行和授权问题诊断。记录运行依赖、fake/真实服务边界、操作、结果和 commit。未接线入口不能写通过。

报告功能 ID 总数及各状态数量、端到端路径、实际集成与 mock 边界、三方 commit、第一遍纠正点、许可证核查和待办。关键入口未验证或适用 ID 未关闭时，结论为未完成。
