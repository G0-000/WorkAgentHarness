## 记录规则
- 一行对应一个可单独理解和验收的行为；按权限、生命周期、入口拆分，不按目录计数。
- 稳定 ID 格式 WAH-域-NNN。引用后不复用；拆分/合并保留旧 ID 并重定向。
- EvoFlow 列包括路径、符号、真实调用者/入口和测试；未追完写待核验。
- AgentFlow 记录第一遍实际行为；WorkAgentHarness 记录路径、commit 和状态。
- 状态：待盘点、已盘点、已理解、最小闭环、功能补齐中、边界待验、已验收、有依据排除。
- 验收需有入口、操作/命令、fake/真实依赖、结果、日期和 commit。排除项仍要记录证据、替代和限制。
