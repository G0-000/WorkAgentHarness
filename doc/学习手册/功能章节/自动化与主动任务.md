## 源码入口和阅读方法

evoflow/scheduler/、core/scheduler/、automation/、proactive/、agents/automation_runtime.py、admin/automation_schedule.py 和 app runner。

对选定场景补全“用户输入/入口 → 注册装配 → 核心行为 → 状态或副作用 → 事件/结果”。每个环节记源码符号和相关测试。至少看一个成功路径、一个关键数据结构和一个错误/权限分支；先找真实 caller 再扩阅读。

## 概念和代码解释

区分本地工具 scheduler、用户 automation、proactive heartbeat 和后台任务；追时区、触发、身份、暂停/恢复、lease、结果和关闭。

每个概念回答：数据由谁创建和拥有、谁能修改、何时持久化、失败时保留什么、用户在哪里看到结果。把概念对应到真实源码，不以 README 的理想图替代当前装配。
