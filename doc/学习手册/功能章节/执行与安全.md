## 从一个问题进入

## 源码入口和阅读方法

evoflow/subagents/、sandbox/、execution_security/、session_execution/、session_tool_binding/、cancellation/；追审批工具、中间件与 app adapter。

对选定场景补全“用户输入/入口 → 注册装配 → 核心行为 → 状态或副作用 → 事件/结果”。每个环节记源码符号和相关测试。至少看一个成功路径、一个关键数据结构和一个错误/权限分支；先找真实 caller 再扩阅读。

## 概念和代码解释

子代理注册/预算/并发/结果；sandbox provider 和虚拟路径；审批、denylist、policy；取消传播、超时、重试、审计与资源释放。路径检查不等于进程隔离。

每个概念回答：数据由谁创建和拥有、谁能修改、何时持久化、失败时保留什么、用户在哪里看到结果。把概念对应到真实源码，不以 README 的理想图替代当前装配。

## 从最小实验到完整能力

1. 写一个具体用户场景、输入输出和依赖关系。
2. 最小闭环：fake executor 跑子任务；加并发限制和状态；接受限 sandbox；再补写操作审批、取消和真实入口集成。
3. 对照本单元原子功能 ID 补齐配置、真实入口、生命周期、错误和边界；WorkAgentHarness 没有的实现仍标为未实现。
4. 从真实入口复现一个不同输入，解释因果链，更新记录和差异。

## 练习与验收

| 验收 | 练习 | 证据 |
|---|---|---|
| 核心契约 | 验证输入、输出和状态变化 | 精确命令、结果、commit |
| 错误/权限 | 越界路径/命令、符号链接、并发上限、取消竞态、审批恢复、失败重试、残留进程和审计。 | 错误、权限结果及副作用 |
| 真实集成 | 从注册入口进入，不绕过装配直调内部函数 | 运行依赖和完整调用链 |
| 生命周期 | 验证适用的重启、取消、删除、卸载或重配置 | 状态变化、恢复和残留资源 |
| 讲解 | 不看笔记复述入口→逻辑→状态→结果并对照第一遍 | 学习记录和结论 |
